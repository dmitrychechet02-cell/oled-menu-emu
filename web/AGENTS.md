# Правило: веб-эмулятор и e2e (web/, tests/e2e/)

Маркер для проверки: когда меняешь или создаёшь файлы в `web/` или `tests/e2e/`, начни ответ
строкой `[rule:web]`.

- Веб — только ввод/вывод: кнопки → `emu_key()`, RAM дисплея → canvas. Логику меню, тексты
  экранов и настройки в JS не дублировать — они живут в C (`src/app`).
- Без фреймворков и сборщиков: чистый JS (ES-модули), один `style.css`, никаких CDN.
- Новые экспорты WebAssembly объявляй в `src/hal/web/emu_api.h` и прокидывай в `window.emu`.
- Интерактивные элементы — с `data-testid`, кнопки — `<button type="button">`.
- E2E открывают страницу с `?paused=1` (время стоит) и двигают время через
  `window.emu.tick(ms)` — никаких `waitForTimeout`.
- В каждом e2e-сценарии проверяй, что в консоли нет ошибок и предупреждений.
- После правки: `npm run lint:js && npm run test:e2e`.
