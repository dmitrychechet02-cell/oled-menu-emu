# Проверка правил по путям — 2026-10-12

Проведены две похожие задачи в отдельных новых чатах Codex в одном проекте.
В запросах не назывались ожидаемые маркеры правил. Ответы проверены чтением
истории чатов, изменения — через git diff.

## Задача в src/

Чат: «Поясни установку пикселя», ID `01a13164-35dd-7f12-85f4-a13f4ec6fd44`.

Запрос:

> В `src/gfx/` добавь короткий поясняющий комментарий к функции установки пикселя.
> Поведение кода не меняй. В ответе перечисли применённые файлы инструкций
> и выполни положенные проверки.

Итоговый ответ начинается с `[rule:firmware]`. В списке применённых инструкций
указаны `AGENTS.md` и `src/AGENTS.md`; `web/AGENTS.md` не указан.

В `src/gfx/gfx.c` перед вычислением индекса добавлен комментарий:

```c
// В SSD1309 байт хранит 8 вертикальных пикселей: выбираем страницу и бит строки.
```

В ответе сообщено: `git diff --check` прошёл; `make lint`, `make test`,
`npm run test:e2e` остановились из-за отсутствия make. Зелёный результат не заявлен.

## Задача в web/

Чат: «Пояснить отрисовку framebuffer», ID `01a13166-dab6-72f2-a4e4-1343c990f772`.

Запрос:

> В `web/emulator.js` добавь короткий поясняющий комментарий к отрисовке framebuffer
> на canvas. Поведение кода не меняй. В ответе перечисли применённые файлы
> инструкций и выполни положенные проверки.

Итоговый ответ начинается с `[rule:web]`. В списке применённых инструкций указаны
`AGENTS.md`, `web/AGENTS.md` и `.agents/skills/check-ui/SKILL.md`;
`src/AGENTS.md` не указан. История показывает чтение web/AGENTS.md и навыка check-ui.

В `web/emulator.js` перед циклом отрисовки добавлен комментарий:

```js
// Каждый бит framebuffer задаёт пиксель, который рисуем на canvas с масштабом SCALE.
```

В ответе сообщено: `node --check` и `git diff --check` прошли;
`make lint`, `make test`, `npm run test:e2e` остановились из-за отсутствия make,
`npm run lint:js` — из-за отсутствия eslint. Агент применил навык check-ui,
но браузерная проверка остановилась на HTTP 404 корневого адреса сервера.

на выбранных примерах; одна пара задач не доказывает изоляцию во всех возможных сценариях.
Так как менялись только комментарии, эксперимент не проверяет выполнение всех
ограничений C-ядра на новой логике.
