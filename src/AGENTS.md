# Правило: код прошивки (src/)

Этот код без изменений должен собираться под микроконтроллер (ARM Cortex-M, ESP32).

Маркер для проверки: когда меняешь или создаёшь файлы в `src/`, начни ответ строкой
`[rule:firmware]`.

- Никакой libc и динамической памяти: только `<stdint.h>`, `<stdbool.h>`, `<stddef.h>`.
  Запрещены `malloc/free`, `printf/snprintf`, `strlen/strcpy/memset` — пиши свои короткие
  циклы или используй `gfx_itoa`. Единственное исключение — `src/hal/web/libc_shim.c`.
- Никакого `float`/`double`: фиксированная точка (например, `temp_x10` = °C × 10).
- Только типы фиксированной ширины (`uint8_t`, `int16_t`); при сужении — явное приведение.
- Нет рекурсии и VLA; буферы — статические или на стеке, размер — константа.
- Зависимости направлены вниз: `app → menu → gfx → fonts`. `gfx` и `menu` не знают про `app`,
  ядро не знает про `hal/web` и браузер.
- Всё, что зависит от железа, — только через `src/hal/display.h`.
- Кадр 1024 байта в раскладке SSD1309: страница = 8 строк, бит 0 — верхний пиксель.
- Каждая новая публичная функция — с unit-тестом в `tests/unit/test_<модуль>.c`.
- После правки: `make lint && make test`.
