# Добавить экран или пункт меню

Процедура для `src/app` + тестов. Делай шаги по порядку, не пропускай тесты.

## 1. Определи тип пункта

| Нужно                         | Тип `menu_item_t`     | Поля                                   |
| ----------------------------- | --------------------- | -------------------------------------- |
| Вложенный список              | `MENU_ITEM_SUBMENU`   | `.submenu`                             |
| Свой полноэкранный экран      | `MENU_ITEM_SCREEN`    | `.screen` (`title`, `draw`, `on_key`)  |
| Вкл/выкл                      | `MENU_ITEM_TOGGLE`    | `.flag`, `.on_change`                  |
| Число в диапазоне             | `MENU_ITEM_VALUE`     | `.value`, `.min/.max/.step`            |
| Выбор из списка               | `MENU_ITEM_CHOICE`    | `.choice`, `.choices`, `.choice_count` |
| Действие                      | `MENU_ITEM_ACTION`    | `.action`                              |

## 2. Строки

Добавь `STR_*` в `src/app/i18n.h` (перед `STR_COUNT`) и обе локали в `src/app/i18n.c`.
Подпись пункта — не длиннее 13 символов (иначе наедет на значение справа).

## 3. Экран (если `MENU_ITEM_SCREEN`)

В `src/app/app.c` по образцу `screen_about`:
- `title()` — строка через `tr()`;
- `draw(gfx_t *g)` — рисуй только ниже шапки: `y >= MENU_ROW_Y0 - 1` (≈12), высота до 63;
  шрифт 5×7, шаг 6 px, крупный текст — `scale` 2–3;
- `on_key()` — вернуть `false` на `UI_KEY_BACK`, чтобы закрыть экран.
Добавь значение в `app_screen_id_t` (`app.h`), ветку в `app_screen_id()` и имя в массив
`SCREENS` в `web/emulator.js` (тот же порядок).

## 4. Иконка (если нужна)

Нарисуй 8×8 в `ICONS` в `tools/gen_font.py` (`#` — пиксель), запусти `make fonts`.
Сгенерированные файлы в `src/fonts/*_data.c` руками не правь.

## 5. Тесты

- Unit: в `tests/unit/test_app.c` — сценарий нажатий через `app_key()` + проверка
  `menu_title()` / `app_screen_id()` / значения настройки.
- E2E: в `tests/e2e/menu.spec.js` — один `test(...)`: открыть экран кнопками, проверить
  `state-title`, консоль без ошибок.

## 6. Проверка

```
make lint && make test && npm run test:e2e
```

Всё зелёное → отметь пункт в `docs/plan.md`.
